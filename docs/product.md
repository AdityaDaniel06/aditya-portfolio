# Product

A personal portfolio for **Aditya Daniel, Full-Stack Developer**, styled like a retro pixel game.

## Goal

Give recruiters and clients a quick, memorable picture of Aditya's skills and experience, and an easy way to get in touch.

## Features

- **Resume sections:** Hero, About, Skills, Experience, Projects, Contact
- **Bug Dash:** a playable endless runner. You jump and stomp bugs, bump code blocks for coins, chain coin combos, unlock a double jump and grab power-ups (extra life, invincibility star, coin magnet).
- **AI chat sidekick:** answers questions about the resume using a free LLM. When the LLM is unavailable or a usage limit is hit, it answers from the resume instead.
- **Contact form:** messages are saved and emailed to Aditya
- **Visit stats:** anonymous page-visit tracking

## Content

All site text and the chatbot's knowledge come from one file: `src/data/resume.ts`.
