# Aditya Daniel · Pixel Portfolio

A retro pixel-game portfolio with a playable mini-game, an AI chat sidekick and a contact form.

**Stack:** Next.js 15 · TypeScript · Tailwind v4 · GSAP · Lenis · Neon · Resend

## Quick start

```bash
npm install
cp .env.example .env.local
npm run db:setup
npm run dev
```

To change the site content, edit `src/data/resume.ts`.
